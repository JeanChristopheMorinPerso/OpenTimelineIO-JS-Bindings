Exposure, not test coverage or full API parity. A row labeled “exposed” means the JavaScript name and member kind match. Overloads, constructor arguments, defaults, return types and correctness are not checked. Matching classes can still have missing members.

The baseline is the pinned Python opentime, core, schema and algorithms APIs, plus native _otio.bundle. It includes Python convenience functions. It does not inventory the entire C++ header surface, experimental C++ editing APIs, adapters, plugins, CLI, exceptions or private helpers. Python protocols are shown separately and excluded from totals. Inherited members are checked on each class; re-exported class/function aliases are counted once.

JavaScript is inspected from install/, including handwritten wrappers and properties, without calling API methods or getters. Rebuild and install after changing bindings or the OTIO pin. Download JSON evidence

An API is a class, function, or member that a program can use. “Missing” means no matching JavaScript name was found. “Shape mismatch” means the name exists, but its form differs, such as a method instead of a property. “Exposed” does not prove the behavior matches.
